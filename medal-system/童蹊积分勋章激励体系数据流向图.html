童蹊社区 · 数据流向

童蹊积分勋章激励体系数据流向

两条主线分页签查看：活动组织与评审（发起 → 报名上传 → 评委打分 → 公示 / 奖状 / 归档）、 积分激励闭环（行为数据 → 积分 → 排行 → 月度结算 / 勋章 → 奖金 / 发放）。 两者在「专项活动积分」处交汇：活动获奖结果作为专项积分方案输入，注入激励闭环的专项勋章与奖金核算。

活动组织与评审

平台管理员 / 园长发起活动，教师报名并上传作品，评委打分（单次评审），最终公示获奖、生成电子奖状并归档。评审结果同时作为专项活动积分的输入，汇入激励闭环。

积分激励闭环

教师四大维度行为数据经积分引擎计算，形成五榜排行；月度结算定级金银铜勋章，再按梯度核算奖金并生成发放清单，中途离职自动剔除。 专项活动获奖作为专项积分 / 奖金独立核算，与月度常规勋章奖金分开。

二 · 计算

积分与排位分 · 怎么算

积分方案决定维度数值如何累计；排位分把各维度数值在全园倒序排名换算，综合榜 = 四项排位分之和。

→
02

积分方案

→
03

维度排名 → 排位分

各维度数值倒序排名，第 1 名得 N 分 … 第 N 名得 1 分，并列同分后续顺延

→
04

综合榜

总积分 = 平台使用 + 家园互动 + 外部推广 + 会员转化 四项排位分之和

排位分规则： 全园在职参与活动教师共 N 名，单维度按数值从高到低倒序排名，第 1 名得 N 分、第 2 名得 N-1 分……第 N 名得 1 分； 并列名次得相同排位分、后续名次顺延。总积分 = 四项排位分之和（综合榜按此排序）。

04

期末汇总清单

离职剔除： 以教师信息表的离职状态字段为准（is_active = false）； 中途离职自动放弃评比资格，发放清单标注「已剔除」及原因，不影响历史数据。 期末总奖金 = 月度常规奖金累计 + 专项活动奖金累计。

教师端在「我的勋章 / 我的奖金」查看个人勋章档案与奖金明细；园长端查看本园清单；清单支持导出对账。
