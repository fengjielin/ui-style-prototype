童蹊社区 · 数据流向

童蹊积分激励体系数据流向

两条主线分页签查看：活动组织与评审（评分标准维护 → 发起 → 报名上传 → 评委打分 → 公示 / 奖状 / 归档）、 积分激励闭环（行为数据 → 积分 → 排行 → 积分获得情况 → 积分公告 / 奖金）。 评分标准为独立维护模块，活动发起时关联；两者相互独立：积分方案不再关联活动， 参与对象为所选幼儿园的全部在职教师，在「积分获得情况」中查看参与对象积分与排位分，并发布积分公告。

活动组织与评审

评分标准为独立维护模块（指标 / 满分上限 / 权重），管理员发起活动时下拉关联（可不关联）；教师报名并上传作品，评委按关联评分标准打分（单次评审）或管理员逐条直接审核，最终公示获奖、生成电子奖状并归档。积分方案与活动相互独立，不再以活动获奖结果折算积分。

二 · 方案与计算

专项积分方案 · 怎么算

积分体系重构后仅保留「专项积分方案」（已与活动解耦）：按所选幼儿园范围界定参与对象，累计四维度积分，再按总积分定名次、换算排位分。

四维度积分累计

→
04

总积分 → 名次 → 排位分

总积分 = 四维之和；按总积分倒序定名次（并列顺延）；排位分 = N − 名次 + 1

参与对象（示例）勾选「童蹊幼儿园」勾选「全部幼儿园」
参与范围童蹊幼儿园全体在职教师全部园区全体在职教师
排位分规则： 参与对象共 N 名，按总积分从高到低排序，第 1 名得 N 分、第 2 名得 N−1 分……第 N 名得 1 分； 并列同分取相同名次、后续名次顺延。积分获得情况与排行榜均按此口径换算。
