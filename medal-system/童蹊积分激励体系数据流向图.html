童蹊社区 · 数据流向

童蹊积分激励体系数据流向

两条主线分页签查看：活动组织与评审（发起 → 报名上传 → 评委打分 → 公示 / 奖状 / 归档）、 积分激励闭环（行为数据 → 积分 → 排行 → 积分获得情况 → 积分公告 / 奖金）。 两者在「专项活动积分方案」处交汇：活动获奖结果作为方案折算标准输入（奖项 → 积分）， 注入激励闭环的积分获得情况与积分公告。

活动组织与评审

平台管理员 / 园长发起活动，教师报名并上传作品，评委按评分标准打分（单次评审）或管理员直接审核，最终公示获奖、生成电子奖状并归档。评审结果同时作为专项活动积分方案的折算标准输入，汇入激励闭环。

积分激励闭环

教师四大维度行为数据形成排行榜；平台管理员按「临时专项活动积分方案」在「积分获得情况」中查看 参与对象的四维度积分 / 总积分 / 排位分 / 名次与可编辑奖金，并可一键发布积分公告—— 参与对象在消息中心收到、在独立公告详情页查看积分汇总。活动获奖结果作为方案折算标准输入，离职教师自动剔除出参与对象。 （勋章体系与奖金管理已随重构移除）

04

总积分 → 名次 → 排位分

总积分 = 四维之和；按总积分倒序定名次（并列顺延）；排位分 = N − 名次 + 1

奖项等级一等奖二等奖三等奖参与奖
折算积分（示例）100 分60 分30 分10 分
排位分规则： 参与对象共 N 名，按总积分从高到低排序，第 1 名得 N 分、第 2 名得 N−1 分……第 N 名得 1 分； 并列同分取相同名次、后续名次顺延。积分获得情况与排行榜均按此口径换算。
