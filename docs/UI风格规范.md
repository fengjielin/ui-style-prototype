# 童蹊幼儿成长平台 · UI 风格规范

> 本规范用于指导 HTML demo 原型制作，保证原型与现有系统的样式布局保持一致。
> 配套原型模板见 `../pc/` 与 `../mobile/`，设计令牌见 `../assets/css/tokens-*.css`。

---

## 一、总览

### 1.1 文档目的与适用对象
- **适用对象**：原型制作者（HTML demo）、前端开发人员。
- **目的**：抽离现有系统（PC 管理后台 + 移动端）的 UI 风格，形成统一规范，作为原型与后续开发的一致性基准。

### 1.2 端别说明
| 端别 | 技术栈 | 目录 | 风格基准 |
|------|--------|------|----------|
| PC 管理后台 | Vue 2 + Element UI | `kindergartenGit/kindergarten-ui` | 新版卡片式（`src/views/base/teacher/index.vue`） |
| 移动端 | uni-app + ColorUI | `kindergartenMobileGit` | 家长/教师/园长首页 + 我的页 + 列表页 |

### 1.3 设计关键词
**温暖 · 童趣 · 橙色主调 · 叶片绿点缀**
- 主色：橙色 `#ff8a00`（品牌/主操作/高亮/导航）
- 配色：叶片绿 `#66cc99`（次操作/成功点缀）
- 视觉氛围：暖白底 `#fff9f0`、浅橙边框 `#ffe8cc`、橙色系阴影泛光

### 1.4 设计原则
1. **一致性**：两端主色同源 `#ff8a00`，组件样式统一引用设计令牌。
2. **视觉层级**：卡片分层、标题 600 字重、次要文字降色。
3. **间距节奏**：PC 20px 页面边距 / 卡片间距；移动端 30rpx 页面边距 / 20rpx 卡间距。
4. **状态明确**：成功/警告/错误/信息四色标签，交互态 hover/active 反馈。

## 五、跨端一致性

1. **主色同源**：PC `#ff8a00` 与移动端 `$primary-color #ff8a00` 完全一致；渐变同为 `#ff8a00 → #ff9f29`。
2. **rpx → px 换算**：750 基准，1rpx = 0.5px；模板移动端一律写 px。
3. **CSS 变量命名**：`--<端别>-<组>-<名>`，端别 `pc`/`mb`，小写 kebab-case；颜色统一 hex 或 rgba。
4. **Element 兜底色**：`#11A983`（青绿）是 Element 默认主题色，仅对未覆盖组件生效；业务主题以橙 `#ff8a00` 为准。

## 七、原型模板使用说明

### 7.1 目录结构与打开方式
- 直接双击 `pc/list.html`、`pc/form-dialog.html`、`pc/snippets.html`、`mobile/home.html`、`mobile/list.html`、`mobile/mine.html`、`mobile/snippets.html`，用浏览器打开即可，**无需构建**。
- 桌面预览移动端：给 `<body>` 加 `class="preview-mobile"` 可居中限宽 480px。

### 7.2 三步拼装法（新原型页）
1. **引入 CSS**：按端别引入令牌 + 基类（PC 用 `tokens-pc.css`+`base-pc.css`；移动端用 `tokens-mobile.css`+`base-mobile.css`）+ `common.css`。
2. **套骨架**：复制对应模板的布局骨架（PC：侧栏+顶栏+内容区；移动端：导航栏+内容区+tabBar）。
3. **填内容**：从 `snippets.html` 复制组件片段，替换业务内容。

### 7.3 演示层规范（分角色 + 数据持久化）

原型系统新增"演示层"能力，与 UI 样式层解耦：

**三层架构**
| 层 | 文件 | 职责 |
|----|------|------|
| 数据层 | `assets/js/data-store.js`（`window.DS`） | mock 种子 + localStorage（前缀 `demo.v1.`）+ `watch` 订阅 |
| 交互库 | `assets/js/prototype.js`（`window.Proto`） | 通用交互 + `registerAction` 注册自定义 action |
| 渲染层 | `assets/js/demo.js` | 各页 `render*` 函数 + 角色注入 + 业务 action |

**分角色**：角色由 `?role=` 参数 > localStorage > 默认 `parent` 解析。角色 → 首页映射见 `README.md`。入口页 `index.html` 提供角色卡选择。

**持久化键**：`demo.v1.role`（角色）、`demo.v1.teachers`（PC 表格）、`demo.v1.notices`（通知列表）、`demo.v1.formLog`（表单提交记录）、`demo.v1.attendance`（出勤状态）。`userProfile/gridModules/tabBar` 为派生数据（由角色即时计算），不入库。

**数据流**：UI action → `DS.set/update` → `DS.watch` 通知 → render 重绘。刷新从 localStorage 恢复；`DS.resetAll()` 恢复默认数据（保留角色）。

**新增 demo 页接入步骤**（详见 README 架构说明）：
1. 引 `demo.css` + 按序引 `data-store.js → prototype.js → demo.js`；
2. 页面留容器 id，在 `demo.js` 加 `renderXxx()` 并在 `init` 注册 `DS.watch`；
3. 按钮加 `data-action`，用 `Proto.registerAction` 注册处理函数。
